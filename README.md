# Road Traffic Accident Analytics using SAS Viya

## Project Overview
This project explores UK road traffic accident data alongside social media (Twitter) text data to
identify factors influencing collision severity and public sentiment around road incidents.

The analysis combines structured data mining and predictive modelling with unstructured text
analytics to support evidence-based road safety decision-making.

## Project Tasks
### Task 0 – Random Sampling
- Selected a reproducible random sample of 3,500 observations using SAS Viya.

### Task 1 – Data Exploration & Preparation
- Exploratory Data Analysis (EDA)
- Data cleaning and validation
- Feature engineering (date, month, time-of-day)
- Class balancing of collision severity

### Task 2 – Predictive Modelling
- Logistic Regression
- Decision Tree (Champion Model)
- Random Forest
- Model comparison using KS (Youden index) and accuracy

### Task 3 – Text Analytics
- Word cloud exploration
- Concept extraction
- Sentiment analysis
- Topic modelling
- Category classification of traffic-related tweets

### Task 4 – Decision-Maker’s Summary
- Strategic insights and policy recommendations based on combined findings

## Key Findings
- Tree-based models significantly outperform traditional statistical models
- Collision severity is driven by non-linear interactions
- Public sentiment around traffic incidents is predominantly negative
- Social media analytics complements structured accident data effectively
